# Хадия

Одностраничный сайт для халал шайханы «Хадия» (Астана, проспект Тауелсиздик, 25). Чистые HTML, CSS и JS, без сборки.

## Запуск

Откройте `index.html` в браузере или поднимите любой статический сервер:

```
python3 -m http.server 8000
```

Для публикации подойдёт GitHub Pages (Settings → Pages → ветка `main`, корень).

## Что редактировать

- `js/data.js` — номер WhatsApp, часы работы и меню. Пока меню пустое, на сайте показывается кнопка «Попросить меню в WhatsApp». Образец раздела меню лежит в комментарии внутри файла.
- `js/i18n.js` — все тексты на русском и казахском. Казахский перевод нужно показать носителю.
- `img/` — фотографии. Сайт сам подхватит файлы, если они лежат с такими именами: `hero.jpg` (арка в первом экране, лучше вертикальное фото), `gallery-1.jpg`, `gallery-2.jpg`, `gallery-3.jpg`. Без файлов блоки не показываются.

## Откуда данные

Адрес, часы, телефоны и рейтинг взяты из карточки 2ГИС, описание и номер для брони из Instagram `@hadiya_shayhana_astana`. Цена завтрака (2 490 ₸) указана в рекламе карточки 2ГИС, состав и время подачи в источниках не нашлись. Перед запуском владелец должен проверить все данные.
