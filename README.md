# Kotiko

Одностраничный сайт котокафе Kotiko (Астана, улица Розы Баглановой, 3/1). Чистые HTML, CSS и JS, без сборки.

Раньше в этом репозитории лежал сайт шайханы «Хадия». Он остался в истории гита, коммит `b6447c3`.

## Фишки

Тёмная тема (кнопка в шапке, запоминается, по умолчанию как в системе), дорожка лапок в шапке показывает прокрутку, котик выглядывает из угла, на телефоне есть плавающая кнопка WhatsApp, в калькуляторе чек сохраняется картинкой. Теги котиков лежат в `tags` в `js/data.js` и взяты из их описаний.

## Страницы

`index.html` (цены и калькулятор), `cats.html`, `classes.html`, `help.html`, `contacts.html`. Ссылки и адрес в браузере без `.html` (GitHub Pages это понимает; в локальном `http.server` откроются только с `.html`). Шапка и подвал повторяются в каждом файле, при правке меню менять нужно все пять.

## SEO

`sitemap.xml`, `robots.txt`, превью `og.jpg` (1200×630, в ссылке `?v=2`, при смене картинки меняйте число, иначе мессенджеры покажут старую) и `404.html` (работает на GitHub Pages, использует `<base href="/hadiya/">`; сайт на домене kotiko.w-smp.in, при смене адреса поправьте base, canonical и sitemap).

## Запуск

Откройте `index.html` в браузере или поднимите статический сервер:

```
python3 -m http.server 8000
```

Для публикации подойдёт GitHub Pages (Settings → Pages → ветка `main`, корень).

## Что редактировать

- `js/data.js` — номер WhatsApp, цена за минуту, часы работы, мастер-классы и список котиков. Весь остальной код подхватывает эти данные сам.
- `img/cats/<id>.webp` — фото котиков, имя файла равно `id` из `js/data.js` (например `img/cats/twix.webp`). Без файла в кружке показывается значок лапки.
- `css/style.css` — цвета и размеры лежат в переменных в начале файла.

## Дизайн

Стиль «наклейки»: толстые контуры, жёсткие тени, цветные блоки. Шрифты Unbounded, Onest и JetBrains Mono подключаются с Google Fonts. Анимации: появление заголовка, котик над чеком следит за курсором, бегущая строка, появление блоков при прокрутке, клубок крутится при скролле. При `prefers-reduced-motion` всё отключается.

## Что на сайте

- Калькулятор «Сколько стоит визит»: будни или выходные, время ползунком, число гостей. Цена за минуту 45 ₸ в будни и 50 ₸ в выходные и праздники.
- Статус «сейчас открыто» по времени Астаны. Праздничные дни он считает как обычные, по дням недели.
- Мастер-классы с кнопкой записи в WhatsApp и готовым текстом сообщения.

## Откуда данные

Цены, правила, мастер-классы, описания котиков и список для помощи взяты со страницы `tapter.one/kotiko_cafe` и из профиля Instagram `@kotiko_cafe`. Адрес, телефон, рейтинг (4,9, 832 оценки) взяты из карточки 2ГИС. Перед запуском владельцы должны проверить все данные, в частности число котиков: в Instagram указано 16, на tapter 18, а в списке на сайте 14 котиков с описаниями.
